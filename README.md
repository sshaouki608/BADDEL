# BADDEL — بدّل

سوق جزائري للبيع والشراء والتبادل.

## الحالة الحالية
هذه هي النسخة التأسيسية للواجهة (Phase 1). لا تتضمن بعد تسجيل دخول فعليًا أو قاعدة بيانات متصلة أو محادثات حقيقية أو نظام تبادل مكتمل.

## التقنيات المستهدفة
- Next.js App Router
- TypeScript
- CSS responsive مع دعم RTL
- Supabase لاحقًا للمصادقة وقاعدة البيانات والتخزين والوقت الحقيقي

## التشغيل محليًا
```bash
npm install
npm run dev
```

## ملاحظات أمنية
لا ترفع ملفات `.env` أو مفاتيح Supabase السرية إلى GitHub. مفاتيح service-role يجب أن تبقى على الخادم فقط.
